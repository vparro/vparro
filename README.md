# Vanderlei Cunha Parro

Professor Titular e Pesquisador Sênior do Instituto Mauá de Tecnologia, coordenador do Núcleo de Sistemas Eletrônicos Embarcados (NSEE). Doutor em Engenharia Elétrica (Poli-USP), IEEE Senior Member, professor convidado da Université PSL.

Trabalho com sistemas embarcados para missões espaciais (PLATO, EnVision, VERITAS), telescópios gigantes (GMT, ELT) e inteligência artificial em saúde (oncologia e cardiologia).

**Linguagens:** Python · Matlab · Simulink · LaTeX
